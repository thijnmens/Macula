# Macula

Macula is a factorio Space age mod designed to teach developers how to create their own space age mods.

> [!NOTE]
> The mod is fully playable, so even if you aren't a developer this mod is still fun to play!

## Features

* Custom Planet
* Unique Mechanics
* Special items

---

## Requirements

* Factorio 2.0+
* Space Age DLC

---

## Installation

### Using the Mod Portal

1. Open Factorio.
2. Navigate to **Mods → Install**.
3. Search for **Macula**.
4. Click **Install**.
5. Restart the game if prompted.

### Manual Installation

1. Download the latest release from the repository's Releases page.
2. Unpack the `.zip` file in your Factorio data directory:
3. Launch Factorio and enable the mod from the **Mods** menu.

## Contributing

Contributions are welcome!

### Reporting Issues

If you find a bug or have a suggestion:

1. Check existing issues first.
2. Open a new issue with:

    * A clear description of the problem.
    * Steps to reproduce.
    * Expected behavior.
    * Screenshots or save files if applicable.

### Pull Requests

1. Fork the repository.
2. Create a feature branch:

```bash
git checkout -b feature/my-new-feature
```

3. Make your changes.
4. Test your changes in-game.
5. Commit using clear commit messages.
6. Open a Pull Request describing what changed and why.

### Development Guidelines

* Keep changes focused and well-scoped.
* Follow existing code style and project structure.
* Update documentation when needed.
* Test with the latest version of Factorio and Space Age.
